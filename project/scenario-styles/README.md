# 12 стилей сценариев — проект для Codex и Claude Code

Папка, в которой нейросеть-агент пишет тебе сценарии Reels по 12 стилям — и складывает их на страницу.

## Как начать

**Codex:** открой приложение Codex → добавь проект → выбери эту папку `scenario-styles`.
**Claude Code:** открой эту папку в Claude Code (в приложении Claude — вкладка Code → выбрать папку).

Напиши агенту:

> Сделай сценарий рилс в стиле Урок про то, как я …

Агент спросит, кто ты и как говоришь (один раз), уточнит факты, напишет сценарий таблицей и сохранит его в `scripts/`.

## Что где

| Что | Где |
|---|---|
| Страница: стили и мои сценарии | `index.html` — открой в браузере |
| Паспорта 12 стилей | `styles/` |
| Мои сценарии | `scripts/` |
| Правила для агента | `AGENTS.md` (Codex), `CLAUDE.md` (Claude Code) |

На странице у каждого стиля — поле «тема и что было» и кнопка «Скопировать просьбу агенту»: вписала тему, скопировала, вставила в чат.

## Полезные просьбы

- «Какой стиль взять для ролика про …?»
- «Сделай сценарий рилс в стиле Треш-история про …»
- «Переделай мой текст по стилю Типичная ошибка: …»
- «Обнови страницу» — если сценарии не появились
