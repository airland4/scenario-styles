# Одно из N правил

## Что это

Короткая шпаргалка на 15–20 секунд без вступления. Первое слово — уже польза. Дальше 5–7 пунктов одной формы, по 1–2 секунды на пункт, и каждый показан на экране. Один пункт — запрет: «нельзя» держит сильнее, чем «можно».
В конце рамка: «И это одно из пяти правил …» — зритель понимает, что увидел только часть. Остальные — в описании или по кодовому слову. Такой ролик сохраняют и пересматривают: за один раз всё не запомнить.

## Когда брать

- У тебя есть набор инструментов, средств или приёмов, которые легко показать
- Хочешь серию: одно имя серии, 5 роликов, одно кодовое слово
- Нужен короткий ролик на сохранения

| Секунды | Накал | Шаг | Что сказать |
|---|---|---|---|
| 0 | 92 | Пункт 1 | Сразу польза, показом |
| 2 | 84 | Пункт 2 | «Это — для…» |
| 4 | 82 | Пункт 3 | «А это — если…» |
| 6 | 90 | Запрет | «Никогда…» |
| 9 | 80 | Пункт 4 | Ещё один пункт |
| 12 | 82 | Пункт 5 | Ещё один пункт |
| 15 | 92 | Рамка | «И это одно из N правил…» |
| 18 | 70 | Призыв | «Остальные — в описании» |

## Шаги

| № | Шаг | Что сказать | Заготовка |
|---|---|---|---|
| 1 | Первый пункт · 0–2 с | Без вступления — сразу действие, показанное на экране | … — только … |
| 2 | Пункты · 2–12 с | 5–7 пунктов одной формы, по 1–2 секунды. Каждый — своя картинка | Это — для …, это — если …, а это — когда … |
| 3 | Запрет | Один пункт — «нельзя» | … — никогда. |
| 4 | Рамка серии | Это часть большего списка, у списка — имя | И это одно из пяти правил … |
| 5 | Призыв | Остальные правила — по кодовому слову или в описании | Остальные — в описании. |

## Пример

Косметолог. Пример придуман, чтобы показать форму: в своём сценарии — только то, что было на самом деле.

| Секунды | Говорю | В кадре |
|---|---|---|
| 0–2 | Ретинол — только вечером. | Тюбик в руке, подпись «ВЕЧЕР» |
| 2–4 | Витамин C — утром, под крем. | Флакон, подпись «УТРО» |
| 4–6 | Кислоты и ретинол в один вечер — никогда. | Два флакона, красный крест |
| 6–9 | SPF — каждый день, даже когда пасмурно. | Солнцезащитный крем, окно с тучами |
| 9–12 | Новое средство — сначала на запястье и ждёшь сутки. | Капля на запястье, «24 ч» |
| 12–15 | А маску — не чаще двух раз в неделю. | Баночка маски, «2×» |
| 15–18 | И это одно из пяти правил домашнего ухода, которые я даю всем клиенткам. | Ты в камеру, плашка «1 из 5» |
| 18–20 | Остальные — в описании. | Стрелка вниз |

## Правила

- Первое слово — уже польза: без «привет», без темы, без «сегодня расскажу»
- 15–20 секунд, 5–7 пунктов, по 1–2 секунды на пункт
- Каждый пункт — своя картинка на экране. Пункт, который нечем показать, вычёркиваем
- Пункты одной формы
- Рамка серии — в конце, одной фразой
- В ролике одно правило из N, не все
