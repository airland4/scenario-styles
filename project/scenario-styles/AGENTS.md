# Стили сценариев — правила для агента

> Codex читает этот файл как AGENTS.md, Claude Code — как CLAUDE.md. Текст в них одинаковый.

## Что это

Проект «12 стилей сценариев» для Reels, Shorts и коротких видео. У каждого стиля — паспорт `styles/NN-<стиль>.md`: что это, когда брать, арка внимания по секундам, шаги с заготовками фраз, пример, правила.
Страница `index.html` — стили и «Мои сценарии». Готовые сценарии — `scripts/`.

## Кто пишет

Файл `about-me.md` в корне проекта: ниша, для кого ролики, как человек говорит (на «ты» или на «вы», его фразы). Файла нет — перед первым сценарием спроси коротко одним сообщением и сохрани ответ туда. Голос сценария — по этому файлу.

## «Сделай сценарий рилс в стиле …»

0. Стиль назван — открой его паспорт. Не назван — спроси, что ролик должен сделать: рассказать историю, объяснить, высказать мнение или продать. Предложи 2–3 подходящих стиля из таблицы, по строке на каждый, и дай выбрать.
1. Сначала проверь, хватает ли фактов: что нужно от человека для этого стиля — в поле «что-нужно». Не хватает — задай вопросы одним коротким списком и жди ответа. Никогда не придумывай цифры, имена, результаты, отзывы и факты. Просят «придумай сам» — ставь пропуск [вписать: …] и скажи, что туда нужно.
2. Пиши по паспорту: порядок шагов, хронометраж из «Арки», «Правила» стиля. Один ролик — один стиль, не смешивай.
3. Пиши так, как человек говорит вслух: короткие фразы, живые слова, без канцелярита. Без «Привет, я…» и «В этом видео я расскажу». Первая фраза — середина истории или сразу польза.
4. Ответ: сверху стиль и длина; дальше таблица «Время | Говорю | В кадре», строка на шаг; снизу число слов (около 3 слов в секунду) и проверка по «Правилам» стиля — «чисто» или что нарушено и почему.
5. Сохрани сценарий в `scripts/<гггг-мм-дд>-<тема-латиницей-через-дефис>.md` в этом виде:

```
---
name: <тема сценария>
стиль: <название стиля>
дата: <гггг-мм-дд>
длина: <сколько секунд>
---

# <тема сценария>

| Время | Говорю | В кадре |
|---|---|---|
| 0–5 | … | … |

- Слов: …
- Проверка: чисто / что нарушено
```

6. Запусти `python3 build.py` — сценарий появится на странице в «Моих сценариях». Python нет — скажи об этом одной строкой, сценарий всё равно сохранён.
7. Покажи сценарий в чате и назови путь к файлу.

## «Переделай мой текст по стилю …»

Разложи текст человека по шагам стиля, покажи, каких шагов не хватает, допиши только из того, что в тексте есть. Недостающие факты — спроси.

## Правила

1. **Паспорт — источник.** Страница собирается из паспортов и сценариев: правишь паспорт — запусти `python3 build.py`. Страницу руками не правим.
2. **Новый стиль** — новый файл `NN-<slug>.md` в `styles/` по образцу соседних: шапка `name`, `группа` (История / Объяснить / Мнение / Продать), `длина`, `схема`, `что-нужно`; разделы «Что это», «Когда брать», «Арка» (Секунды | Накал | Шаг | Что сказать), «Шаги» (№ | Шаг | Что сказать | Заготовка), «Пример» (Секунды | Говорю | В кадре), «Правила». Потом `python3 build.py`.
3. **Только реальные детали.** Цифры, имена, результаты, отзывы — только от человека.
4. **Один ролик — один стиль.**
