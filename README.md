# 12 стилей сценариев для Reels

Стиль сценария — это порядок, в котором говорить, чтобы ролик досматривали. Здесь 12 стилей: у каждого — что это, когда брать, арка внимания по секундам, шаги с заготовками фраз, пример и правила.

**Сайт:** https://airland4.github.io/scenario-styles/

## Три способа пользоваться

### 1. Сайт — для всех
Открой сайт → один раз заполни «О себе» → выбери стиль → впиши тему и что было → «Скопировать промпт» → вставь в ChatGPT, Claude или Gemini.

### 2. Проект для Codex и Claude Code
Скачай [scenario-styles-project.zip](https://airland4.github.io/scenario-styles/scenario-styles-project.zip), распакуй и открой папку `scenario-styles` в Codex или Claude Code. Напиши: «Сделай сценарий рилс в стиле Урок про …». Готовые сценарии собираются на странице проекта.

Или попроси агента:

```
Скачай https://github.com/airland4/scenario-styles и положи папку project/scenario-styles к себе. Открой её как проект и прочитай README.md.
```

### 3. Раздел для своего портала
Скачай [scenario-styles-module.zip](https://airland4.github.io/scenario-styles/scenario-styles-module.zip), папку `scenario-styles` положи в корень своей среды и вставь агенту текст из `scenario-styles/INSTALL.md`. Раздел встанет в меню и возьмёт цвета и шрифты твоего портала.

Или попроси агента:

```
Скачай https://github.com/airland4/scenario-styles, папку module/scenario-styles положи в корень моей среды и выполни инструкцию из scenario-styles/INSTALL.md.
```
